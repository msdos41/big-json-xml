# A list entry is not also drawn as a record table

On a list table the columns are that entry's fields. Expanding an entry does not embed a second, vertical copy of the same fields. A record table is used only when the element is not an entry: the document element, a child that occurs once, or a single complex child embedded in a cell. This drops the "open this row as a vertical form" picture for anything that already has two or more siblings.
