# JSON scalars are shown as JSON literals

A string is shown in double quotes, decoded, with quotation mark and backslash escaped. A number, true, false, and null are shown as in the file, without quotes. An empty string is `""`. A missing key is a blank cell. A collapsed object is `{}`. Raw source escapes and a type word in front of each value were rejected: the kind stays visible, and the text stays readable.
