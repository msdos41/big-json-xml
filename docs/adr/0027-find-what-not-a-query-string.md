# Find what replaces the query string

Search is entered as Find what, a character sequence, not as `name = value` or `name ~ value`. It tests element names, attribute names, and values, and each of those can be turned off. The tested text contains Find what, starts with it, or equals it. Match case is on unless the user turns it off. A field name, a parent element name, a grandfather element name, and a parent attribute name can narrow the hits. An empty Find what still has no hits. There is no wildcard and no replace. ADR-0013's query grammar is retired. A hit still stores a path, revealing it still expands that path on the one scroll surface, and there is still no XPath.
