# A list is same parent, same name, not necessarily consecutive

Sibling elements belong to one list when they share a parent and a name. A different-named sibling does not join that list and does not split it. Consecutive-only grouping (XiMpLe) would shatter GB documents that interleave an occasional other tag. Structural-similarity grouping has no stable rule without a schema.

A list becomes a list table only when it has two or more elements. A single occurrence is a field on a record table (ADR-0008).
